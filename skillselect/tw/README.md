# 繁中版使用說明

網址： https://614tools.top/skillselect/tw/

這是「種馬技能篩選器」內的獨立繁中分頁，可透過工具內的日服／繁中服頁籤互相切換。原站首頁沒有新增入口，日服資料與篩選邏輯保持原樣。

預設收錄 344 個白技能、209 名育成馬娘、336 張 SSR / SR。繁中譯名按技能 ID 對應 BWIKI；支援日文、繁中及技能 ID 搜尋、逐行轉換及 CSV 匯出。

目前版本依 2026/09/22 繁中唯獨愛你卡池對照日服 2025/05/21 進度。這是推定範圍，並非當期繁中 master.mdb 逐條核驗版。也可切換到公開繁中 2024/06/27 歷史庫。日服事件參考預設關閉，日服馬身收益表未套用。
