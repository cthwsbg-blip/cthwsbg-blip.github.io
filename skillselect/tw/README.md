# 繁中版使用說明

網址： https://614tools.top/skillselect/tw/

這是「種馬技能篩選器」內的獨立繁中分頁，可透過工具內的日服／繁中服頁籤互相切換。原站首頁沒有新增入口，日服資料與篩選邏輯保持原樣。頂部介紹模組已移除，日繁名稱對照位於工具列，資料版本與來源說明位於 Tips 規則說明視窗。

預設收錄 380 個白技能、227 名育成馬娘、360 張 SSR / SR。繁中譯名按技能 ID 對應 BWIKI；支援日文、繁中及技能 ID 搜尋、逐行轉換及 CSV 匯出。

繁中已於 2026/10/29 開放無人島；本版本依需求預先收錄日服 2025/06/27 開篇至 2025/10/27 的四個月卡池，並補齊舊版 2025/05/21 後遺漏。範圍含繁中尚未實裝內容，供後續規劃。數值主體採日服 2025/10/10 快照；10/18 緞通烈焰另以 2025/12/26 公開技能表補充並對照首發資料，並非當期繁中 master 核驗。新增 18 張育成卡、24 張支援卡和 36 個白技能，含舊版遺漏。也可切換到公開繁中 2024/06/27 歷史庫。事件參考預設勾選，可在工具列手動切換。進度內卡片的事件技能及金技→白技會計入來源、已提供技能與推薦；事件取得條件參考原作資料，尚未逐一核對當期繁中。日服馬身收益表未套用。
